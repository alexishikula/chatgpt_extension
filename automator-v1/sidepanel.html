JSON protocol examples

PM routes downward by specifying target_agent_id.

<<AUTOMATOR>>
{
  "action": "DISPATCH_TASK",
  "task_id": "TEST-001",
  "target_agent_id": "qa_reviewer",
  "assignment": "Review the work and report your result."
}
<<END_AUTOMATOR>>

Agents never specify a destination. Automator returns the result to the PM stored on the task.

<<AUTOMATOR>>
{
  "action": "TASK_RESULT",
  "task_id": "TEST-001",
  "status": "COMPLETE",
  "summary": "Review completed."
}
<<END_AUTOMATOR>>
